# CurioTech & CareerCafe Specialized AI Agent Skills (`ct-skills`)

This directory houses specialized, production-frozen AI agent skills dedicated specifically to the **CurioTech** and **CareerCafe** product ecosystem (`CurioTech-CareerCafe`).

Unlike the universal catalog in `.agents/skills/`, the skills here encapsulate the exact brand guidelines, design tokens, typography rules, surface behaviors, and landing page architecture defined in **CareerCafe Visual Design System & Landing Page Handoff v3.2**.
